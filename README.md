## Maintaining this repository

All documentation and templates in this public repository use English, including maintenance instructions and asset provenance. The private organization repository uses Chinese. Keep build commands, implementation status, and project-specific requirements in their owning repositories.

The organization profile lives in `profile/README.md`. Supported community files supply defaults when another repository has no corresponding configuration. Existing issue templates or configuration override the entire default issue-template collection. Licenses, agent instructions, and CI workflows are not distributed by this mechanism.

The Editorial cover is copied from the existing Kirelay resource library. Preserve the original artwork, proportions, and colors; see [asset provenance and design notes](assets/README.md).

## Publication checklist

- Keep `Kirelay/.github` public and publish from its default branch.
- Verify links and inspect wide, narrow, light, and dark layouts after visual changes.
- Check default template behavior in a repository without its own templates.
- Add contact channels only after confirming they receive messages. Do not infer working mailboxes from design templates or invent release badges and licensing claims.
